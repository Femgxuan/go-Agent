## 一、核心创作哲学

### 1.1 诗歌的本质

> **"诗歌是在沉默的边缘，用最少的词语说出最多的话。"**

诗歌创作应遵循以下核心理念：

- **精炼** — 每一个词都有其存在的理由
- **意象** — 用具体的形象表达抽象的情感
- **节奏** — 语言的音乐性是诗歌的灵魂
- **留白** — 不说完，留给读者想象的余地
- **真诚** — 最打动人的永远是源自内心的声音

### 1.2 诗歌的三种境界

```
第一层：工整与技巧（韵律对仗、修辞手法）
  ↓
第二层：意象与意境（画面感、氛围营造）
  ↓
第三层：共鸣与余韵（读完还在心里回响）
```

## 二、诗体指南

### 2.1 现代诗（自由诗）

**特点**：不拘格律，注重意象和内在节奏

```markdown
### 创作要点
- **意象选择**：用具体的物象承载抽象的情感
  - 例："我的思念是/一列永远不会准点的火车"（思念→火车）
- **分行与断句**：分行即呼吸，断句即停顿
  - 在需要强调的词后换行
  - 用跨行制造悬念
- **语言的陌生化**：把熟悉的东西写得陌生
  - ❌ "我很孤独"
  - ✓ "我的影子今天/忘了跟我回家"
- **留白**：不要解释意象，让意象自己说话
```

**经典示例**：
```
《错误》—— 郑愁予

我打江南走过
那等在季节里的容颜如莲花的开落

东风不来，三月的柳絮不飞
你的心如小小的寂寞的城
恰若青石的街道向晚
跫音不响，三月的春帷不揭
你的心是小小的窗扉紧掩

我达达的马蹄是美丽的错误
我不是归人，是个过客……
```

### 2.2 古体诗

**特点**：讲究格律、平仄、对仗、押韵

```markdown
### 主要形式

| 形式 | 句数 | 每句字数 | 押韵要求 |
|------|------|---------|---------|
| **五绝** | 4句 | 5字 | 一、二、四句押韵 |
| **七绝** | 4句 | 7字 | 一、二、四句押韵 |
| **五律** | 8句 | 5字 | 偶句押韵，中间两联对仗 |
| **七律** | 8句 | 7字 | 偶句押韵，中间两联对仗 |
| **古风** | 不限 | 不限 | 较自由 |

### 平仄基础
- **平声**：阴平（¯）、阳平（ˊ）
- **仄声**：上声（ˇ）、去声（ˋ）、入声（短促）
- 基本句式：平平仄仄平平仄 / 仄仄平平仄仄平

### 对仗要求（律诗）
- **词性相对**：名词对名词，动词对动词
- **结构相对**：偏正对偏正，动宾对动宾
- **意义相对**：同类事物的呼应
```

**示例（创作）**：
```
《秋夜寄怀》

西风凋碧树，落叶满空庭。
独坐寒窗下，遥看北斗星。
故园千里外，归梦几时醒。
欲问南飞雁，家书可曾停？
```

### 2.3 俳句

**特点**：日本传统短诗，以"季语"和"切字"为特色

```markdown
### 格式
- 五·七·五 共17个音节（日语原文）
- 中文俳句可灵活处理，但保持简洁

### 要素
1. **季语** — 暗示季节的词语（如：樱花→春，蝉→夏，红叶→秋，雪→冬）
2. **切字** — 表示停顿或感叹的助词（中文可用"呀""哦""啊"等）
3. **当下** — 描写此刻此地的所见所感

### 创作原则
- 写眼前景，抒当下情
- 用具体的细节暗示宏大的意境
- 避免抽象概念和主观评价
```

**经典示例（松尾芭蕉）**：
```
古池や
蛙飛び込む
水の音

（古池塘呀
青蛙跳入
水声响）
```

### 2.4 十四行诗（Sonnet）

**特点**：源自意大利的抒情诗体，结构严谨

```markdown
### 两种主要体式

#### 意大利式（彼得拉克式）
- **前八行**（八行诗段）：提出问题或描述情景，韵式 abba abba
- **后六行**（六行诗段）：回应或转折，韵式 cde cde / cdc dcd

#### 英国式（莎士比亚式）
- **三个四行诗段**：层层推进，韵式 abab cdcd efef
- **最后两行对句**：总结或点题，韵式 gg
```

**示例（莎士比亚第十八首）**：
```
Shall I compare thee to a summer's day?
Thou art more lovely and more temperate:
Rough winds do shake the darling buds of May,
And summer's lease hath all too short a date...
```

### 2.5 散文诗

**特点**：不分行，但具有诗意的语言和内在节奏

```markdown
### 创作要点
- **诗意的语言**：用词的音韵美和画面感
- **内在的节奏**：通过长短句变化制造韵律
- **集中的意象**：围绕一个核心意象展开
- **叙事与抒情的结合**：在叙述中融入诗意
```

## 三、创作方法论

### 3.1 从灵感到成诗的五步法

```
灵感 ──→ 意象 ──→ 结构 ──→ 草稿 ──→ 打磨
```

#### 第一步：捕捉灵感
- 一个画面（"雨打在梧桐叶上的样子"）
- 一种情绪（"黄昏时莫名的忧伤"）
- 一个句子（"月光是时间的灰烬"）
- 一个联想（"地铁站里的人群像洄游的鱼"）

#### 第二步：寻找核心意象
- 找到最能承载情感的物象
- 用多个感官描写同一意象
- 赋予意象独特的个人色彩

#### 第三步：选择结构与形式
- 看灵感适合哪种诗体
- 确定大致的长短和节奏
- 规划意象的展开顺序

#### 第四步：写出初稿
- 不要追求完美，先把想说的写下来
- 跟着感觉走，不要被格律束缚
- 保持真诚，不要故作高深

#### 第五步：打磨与修改
```
逐层修改：
1. 意象 —— 是否准确？是否新颖？
2. 词语 —— 还有更精确的词吗？
3. 节奏 —— 读起来顺吗？分行合理吗？
4. 删减 —— 有没有可以去掉的词？
5. 音韵 —— 有没有押韵的可能（如果需要）？
```

### 3.2 日常灵感训练

帮助用户培养诗意的眼光：

| 练习 | 方法 | 频率 |
|------|------|------|
| **观察日记** | 每天记一个最打动你的瞬间 | 每日 |
| **词语银行** | 收集优美/有趣的词语和搭配 | 随时 |
| **仿写练习** | 仿写一首你喜欢的诗 | 每周 |
| **限时创作** | 5分钟内写一首短诗 | 每周 |
| **意象日记** | 每天找一个意象来描写心情 | 每日 |

## 六、常用修辞技巧

### 6.1 意象与修辞速查

| 技巧 | 说明 | 示例 |
|------|------|------|
| **比喻** | 用相似的事物打比方 | "月光如流水一般" |
| **拟人** | 赋予物以人的特征 | "风在说悄悄话" |
| **通感** | 不同感官的联通 | "听见了颜色的声音" |
| **象征** | 用具体事物代表抽象概念 | "灯塔代表希望" |
| **反讽** | 说反话制造张力 | "多美的战争啊" |
| **排比** | 并列结构增强气势 | "我爱你/像飞蛾爱火/像海浪爱岸" |
| **反复** | 重复关键词强化印象 | "等待/在每一个路口等待" |
| **倒装** | 改变语序制造陌生感 | "来了，春天" |

### 6.2 词语搭配建议

| 情感 | 建议用词 |
|------|---------|
| **喜悦** | 明媚、轻盈、绽放、雀跃、温暖 |
| **忧伤** | 黯淡、飘落、潮湿、断裂、泛黄 |
| **思念** | 遥远、绵长、模糊、潮汐、影子 |
| **宁静** | 缓慢、透明、沉睡、融化、浮云 |
| **激昂** | 燃烧、奔腾、锋利、呼啸、迸裂 |
| **怀旧** | 陈旧、褪色、尘埃、回响、泛黄 |

## 九、诗歌创作示例库

按需调用，帮助用户理解不同风格：

### 现代诗示例

```markdown
《地铁站》

人群在隧道的风口
变成洄游的鱼群
刷卡机的嘀声
是潮汐的节奏

一个女孩靠在门边
耳机里的旋律
是她给自己画的
一道透明围栏

列车启动的瞬间
所有面孔模糊成
印象派的色块
只有广告屏上的笑容
永远明亮
```

### 俳句示例

```
春夜雨
一滴一滴数到
天明

———

夏蝉声
把午后的寂静
拉得更长

———

落叶上
写了一句诗
被风吹走
```

### 古体诗示例

```
《山居》

空山新雨晚来秋，
一径松风入小楼。
半卷闲书茶未冷，
不知明月上帘钩。
```
